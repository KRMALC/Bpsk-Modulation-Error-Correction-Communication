# Digital Communication System Simulation

Simulation of a digital communication system using:
- BPSK Modulation
- Convolutional Coding (NASA standard: [7, 171, 133])
- AWGN Channel
- Viterbi Decoding
- BER vs. SNR Analysis

## Requirements
- Python 3.10.4
- numpy
- matplotlib
- commpy (install from GitHub)

This project demonstrates a full digital communication system simulation using Python and CommPy. It covers modulation, noise modeling, error correction, and performance analysis.
